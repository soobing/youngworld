■ 음악 (bgm.mp3)
   이 영상을 위해 직접 합성했습니다. 외부 음원을 쓰지 않았습니다.

   만든 방법: 같은 폴더의 music.js — Node.js 로 파형을 직접 계산해 WAV 로
             쓰고, ffmpeg 로 mp3 로 인코딩했습니다. 악기 소리도 사인파와
             노이즈에서 만들었습니다(패드·베이스·킥·스네어·하이햇·크래시·멜로디).

   다시 만들려면:
       node public/works/ahn/dream/music.js
       ffmpeg -y -i public/works/ahn/dream/bgm.wav \
              -c:a libmp3lame -b:a 192k public/works/ahn/dream/bgm.mp3
     난수 시드를 고정해 두어서 몇 번을 돌려도 똑같은 파일이 나옵니다.
     (bgm.* 는 .gitignore 대상이라 음원 파일 자체는 저장소에 없습니다.
      대신 music.js 가 커밋되어 있으니 다른 컴퓨터에서도 복원됩니다)

   길이:     27.5초  (영상에는 앞 26초만 사용, 페이드 인 2초 / 아웃 3초)
   형식:     44.1kHz · 스테레오 · 192kbps
   빠르기:   96 BPM · 4/4 — 한 컷(5초)이 정확히 2마디가 되도록 맞췄습니다.
             그래서 컷이 바뀌는 자리에 마디의 첫 박이 떨어집니다.
   코드진행: Am–F–C–G · Am–F–C–G · F–G–C
             가단조로 시작해 마지막에 다장조로 풀립니다.

   컷에 맞춘 강약 (구간별 실측 평균 음량)
       컷1  객석      패드만, 드럼 없음          -29.6 dB
       컷2  첫날      킥이 조심스럽게 들어옴     -22.3 dB
       컷3  첫 박     크래시와 함께 드럼 전부    -19.9 dB
       컷4  한국사    드럼을 덜고 멜로디가 나옴  -21.4 dB
       컷5  큰 무대   전부, 가장 크게            -19.0 dB
     전체 피크 -1.6 dB (클리핑 없음)

   라이선스: 이 작품을 위해 새로 만든 것이라 별도의 사용 조건이 없습니다.
            외부 저작물을 쓰지 않았으므로 출처 표기 의무도, 배포 제한도
            적용되지 않습니다.
