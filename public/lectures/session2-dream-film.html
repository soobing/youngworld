⭐ 「나의 꿈은」 영상 만들기

내 꿈을 26초짜리 영상으로 만들어 교실 작품 갤러리에 겁니다.
그림도 영상도 처음이어도 괜찮아요. AI 도우미가 옆에서 같이 만듭니다.

이 문서는 컴퓨터 용어를 하나도 몰라도 따라올 수 있게 썼습니다. 모르는 말이 나오면 그냥 넘기지 말고, 아래 「먼저 알아둘 말 6개」를 다시 보세요. 그래도 모르겠으면 선생님이나 AI에게 그냥 물어보면 됩니다.

완성하면 이렇게 됩니다

교실 → 오른쪽 작품 구역 → 내 이름표 클릭 → ⭐ 나의 꿈은? 칸이 켜지고, 누르면 내 영상이 음악과 함께 재생됩니다. 먼저 soobing 선생님 작품을 열어보고 오세요. 그게 완성 예시입니다.

1. 먼저 알아둘 말 6개 이것만 알면 끝

그 까만 창 안에서 나랑 대화하는 AI예요. 한국말로 말해도 알아듣고, 파일도 직접 만들어 줍니다.

💬 "내 꿈 영상 만들어줘" 라고 한국말로 치면 됩니다.

Claude 안에 있는 이 일만 전문으로 하는 도우미예요. 그냥 Claude에게 물어보면 이것저것 다 하지만, dream-film을 부르면 "꿈 영상 만들기" 순서를 정확히 알고 있는 전문가가 나옵니다.

💬 병원에서 "그냥 의사" 말고 "치과 선생님"을 찾아가는 것과 같아요.

빌드 build · 조립

흩어진 재료를 모아서 완성품 하나로 조립하는 것이에요. 우리는 그림 5장 + 자막 5줄 + 음악 1개를 넣으면 영상 1개가 튀어나옵니다.

💬 재료를 냄비에 넣고 끓이면 요리가 나오는 것과 같아요. 명령어 한 줄이면 됩니다.

README 리드미 · "읽어주세요"

폴더 안에 들어 있는 사용설명서 파일이에요. "이 폴더엔 뭘 넣어야 한다"가 적혀 있습니다. 컴퓨터가 읽는 게 아니라 사람이 읽으라고 둔 거예요.

💬 새 게임 상자를 열면 들어 있는 설명서와 같아요.

경로 path · 파일 주소

파일이 어느 폴더 안에 있는지 알려주는 주소예요. / 는 "그 안으로 한 칸 들어가라"는 뜻입니다.

5. 그림 5장 만들기 제일 중요한 단계

  1. 주문서(프롬프트)를 복사합니다. AI가 영어로 5개를 줄 거예요. 영어를 몰라도 됩니다. 그냥 복사만 하면 돼요.
  2. 01번 그림을 먼저 만듭니다. 마음에 들 때까지 다시 뽑으세요. 이 한 장이 나머지 4장의 기준이 됩니다.
  3. 02~05번을 만들 때, 01번 그림을 같이 첨부합니다. "이 사람과 같은 그림체로 그려줘" 라고 덧붙이면 더 좋아요.
    이렇게 안 하면 장면마다 얼굴이 딴사람이 됩니다. 이게 제일 흔한 실패예요.
  4. 다 되면 내 폴더 안 frames 폴더에 저장합니다. 이름은 반드시 01.png ~ 05.png.

출처는 왜 남겨야 하나요?

우리 작품은 진짜 인터넷에 공개됩니다(youngworld-ai.com). 남이 만든 음악을 쓸 땐 "이건 누가 만든 거고 어디서 받았다"를 남기는 게 만든 사람에 대한 예의이고, 나중에 문제가 생겼을 때 나를 지켜주는 기록이기도 해요.

8. 막혔을 때 눌러서 펼쳐보세요

😵 장면마다 얼굴이 딴사람이에요

제일 흔한 문제예요. 01번 그림을 참고 이미지로 첨부하지 않아서 그렇습니다. 02~05번을 다시 만들 때 01번 그림을 같이 올리고 "같은 사람, 같은 그림체로"라고 써주세요. 교복이나 머리 길이처럼 눈에 띄는 특징을 주문서에 적어두면 더 잘 유지됩니다.

🔇 영상에 자막이 안 나와요

한글 글꼴을 못 찾은 경우예요. 영상은 정상이니까 그냥 두어도 되고, AI에게 "자막이 안 나와"라고 말하면 확인해 줍니다.

🖼 그림이 흐릿하고 뿌예요

그림이 너무 작게 만들어졌을 수 있어요. 그림 AI에서 가로로 긴(16:9) 큰 크기로 다시 뽑아보세요. AI에게 "그림이 흐릿해"라고 말하면 화면 크기를 맞춰 다시 조립해 줍니다.

👻 갤러리에 내 작품이 안 보여요

보통 두 가지예요. ① 영상 파일이 아직 안 만들어졌거나, ② 서버를 껐다 켜지 않았거나. AI에게 "갤러리에 안 보여"라고 말하면 찾아줍니다.

🤔 무슨 말인지 하나도 모르겠어요

그냥 물어보세요. AI에게 "빌드가 뭐야?", "이 폴더 어디 있어?", "지금 뭘 해야 해?" 라고 한국말로 치면 됩니다. 몇 번을 물어도 괜찮아요. 선생님한테 손 드는 것도 언제든 환영입니다.

9. 꼭 지킬 것 세 가지

① 사실을 쓰세요. 멋있게 보이려고 없는 일을 지어내지 마세요. "꿈의 씨앗" 같은 폼나는 말보다 "초등학교 5학년 때 스틱맨 영상을 처음 봤다"가 백 배 좋습니다. 진짜 있었던 일이 제일 강해요.

② 남의 작품을 베끼지 마세요. 친구 작품이 잘 나왔다고 그림체와 색까지 따라 하면 둘 다 시시해집니다. AI에게 "다른 사람들이랑 다른 느낌으로 해줘" 라고 말해도 돼요.

③ 음악 출처를 남기세요. 5번 항목에서 설명한 그거예요. 빠뜨리지 마세요.
