# 🎬 dream-film — 그림 5장을 26초 영상으로

「나의 꿈은」(작품 갤러리 slot 1) 전시용 영상을 만드는 도구입니다.
**AI 영상 생성 구독 없이**, 로컬 `ffmpeg` 만으로 슬라이드쇼가 아닌 "영상"을 만듭니다.

```bash
./tools/dream-film/build.sh soobing
```

## 준비물

```
public/works/<슬러그>/dream/
  frames/01.png 02.png 03.png 04.png 05.png   ← 1920x1080 그림 5장
  captions.txt                                 ← 한 줄 = 한 컷 자막 (5줄)
  bgm.mp3                                      ← 배경음악
  credits.txt                                  ← 음악 출처·라이선스 (전시물이라 필수)
```

`ffmpeg` 이 없으면 `brew install ffmpeg`.

## 결과물

```
public/works/<슬러그>/dream/dream.mp4     26초 · 1920x1080 · h264+aac · 약 4~9MB
public/works/<슬러그>/dream/poster.jpg    재생 전에 보이는 첫 화면
```

`dream.mp4` 가 생기면 서버 재시작 시 **갤러리 「나의 꿈은?」 칸이 자동으로 켜집니다**
(`server/seed.js` 가 파일 존재를 확인해서 등록합니다).

### 저장소에 들어가는 것 / 안 들어가는 것

| | git | 왜 |
|---|---|---|
| `dream.mp4` · `poster.jpg` | ✅ 커밋 | 전시물 본체. 이게 있어야 갤러리가 켜진다 |
| `captions.txt` · `credits.txt` | ✅ 커밋 | 자막 원문과 음악 라이선스 기록 |
| `frames/*.png` | ❌ 무시 | 사람당 ~11MB. 프롬프트로 다시 만들 수 있다 |
| `bgm.mp3` | ❌ 무시 | ~5MB. `credits.txt` 의 URL 로 다시 받으면 된다 |

그래서 **다른 컴퓨터에서 받으면 그림과 음악은 없습니다.** 자막만 고쳐 다시 빌드하려면
`credits.txt` 를 보고 음악을 다시 받고, 그림은 `.claude/agents/dream-film.md` 의
프롬프트로 다시 생성하세요. (규칙은 `.gitignore` 참고)

## 그림은 어떻게 만드나

Claude 에게 **"dream-film 으로 <슬러그> 꺼 만들어줘"** 라고 하면
`intro.html`(자기소개)을 읽고 → 5컷 스토리보드 + **이미지 생성 프롬프트**를 뽑아줍니다.
그 프롬프트를 nanobanana·ChatGPT 등 원하는 이미지 생성 도구에 넣어 그림을 받고,
`frames/` 에 `01.png` ~ `05.png` 로 저장하면 됩니다.

> 인물이 컷마다 딴사람이 되는 걸 막으려면 **01 을 먼저 확정한 뒤, 그 이미지를
> 02~05 생성 시 참조 이미지로 첨부**하세요. 이게 일관성의 90%입니다.

## 무엇이 "영상처럼" 만들어 주나

| 기법 | ffmpeg 필터 | 효과 |
|---|---|---|
| 켄 번스 (카메라 무빙) | `zoompan` | 정지 그림 안에서 카메라가 천천히 줌·팬 |
| 크로스페이드 | `xfade` | 컷과 컷이 잘리지 않고 녹아서 이어짐 |
| 한 박자 쉼 | `xfade=transition=fadeblack` | 마지막 직전 전환에서 검은 화면을 스쳐감 |
| 톤 통일 | `noise` + `vignette` | 서로 다른 그림 5장이 한 편처럼 보임 |
| 자막 | `drawtext` | 컷이 온전히 보이는 구간에만 등장 |
| 음악 | `afade` | 앞 2초 페이드인 / 끝 3초 페이드아웃 |

컷 번호에 따라 카메라 무빙이 자동으로 달라집니다
(①느린 줌인 → ②좌→우 팬 → ③강한 줌인 → ④아래→위 팬 → ⑤줌아웃).

## 진짜 움직이는 컷을 섞고 싶다면

`frames/03.mp4` 처럼 **mp4 를 넣어두면 그 컷만 zoompan 을 건너뛰고 영상을 그대로 씁니다.**
스크립트를 고칠 필요가 없습니다. 6초보다 짧으면 마지막 프레임을 늘려 채웁니다.

무료로 5초 클립을 뽑을 수 있는 곳(2026-07 기준, 웹 UI 한정):
- **Google Flow** — 비구독자 하루 50 크레딧
- **Hailuo / Kling** — 일일 무료 크레딧

> API 는 전부 유료입니다(Veo 3.1 = $0.40/초). 그래서 기본 경로는 ffmpeg 입니다.

## 튜닝

`build.sh` 맨 위 설정값만 만지면 됩니다.

| 값 | 기본 | 의미 |
|---|---|---|
| `CLIP` | 6 | 컷 길이(초). 5초 노출 + 1초 겹침 |
| `XF` | 1 | 크로스페이드 길이(초) |
| `W`/`H` | 1920/1080 | 최종 해상도. 용량이 크면 1280/720 |
| `CRF` | 23 | 화질. 낮을수록 고화질·큰 용량 (18~28) |

컷 수는 자동입니다. 3장을 넣으면 16초, 7장을 넣으면 36초가 됩니다.
(`총 길이 = 컷수 × 5 + 1` 초)

## 자주 만나는 상황

- **자막이 안 나옴** — 한글 폰트를 못 찾은 겁니다. macOS 면 자동으로 잡히고,
  없으면 자막만 빼고 영상은 정상으로 나옵니다(경고 메시지 확인).
- **줌이 덜덜 떨림** — 그림이 1920x1080 보다 작을 때 생깁니다. 원본을 크게 받으세요.
- **용량이 15MB 넘음** — 스크립트가 경고합니다. `CRF` 를 28 로 올리세요.
- **음악이 26초보다 짧음** — 알아서 반복해서 채웁니다. 신경 쓸 필요 없습니다.
